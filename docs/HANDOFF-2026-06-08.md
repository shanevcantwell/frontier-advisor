# Handoff — 2026-06-08: The advisor reaches the intelligence ceiling via the Claude CLI

**Repo:** frontier-advisor · **Branch:** main · **Merged:** `e017745` (commits `70f2d80` core, `e017745` scaffolding) · **Issue:** #1

## What changed here

The advisor's top tier now invokes the local `claude` CLI (Opus via OAuth) instead
of the metered Anthropic HTTP API; OpenAI (`gpt-4.1`) is the availability fallback
*below* it. The `pi/` TypeScript mirror extension was deleted. Product scaffolding
(Dockerfile, installers, mcp.json, docs) was reworked to the CLI/OAuth model — the
image bundles the CLI, OAuth creds arrive via a read-only `~/.claude` mount, **no
secrets baked into image layers**. Build-verified; `pytest` 45 passed.

## The connective thread — read this before touching the code

**This repo is not "an MCP tool that proxies a model API."** It is the
**intelligence-ceiling escalation primitive** — `consult_advisor()`. The local
orchestrator normally delegates *downward* to subagents to absorb noise; the
advisor is the one inversion: a leaf dispatch that reaches a tier **more capable
than the caller itself.** *Call down to delegate up.* Framing it as a generic
"provider proxy" is what produced confusion in the first design pass — `claude_cli`
is **the ceiling's transport, not a peer of OpenAI.**

Three throughlines connect this change to the rest of the effort:

1. **It depends on pi-jail.** The CLI path only stays flat-rate because
   `ANTHROPIC_API_KEY` was removed from the `pi-agent` container (pi-jail#2) — an
   injected key would shadow the OAuth Max creds and re-introduce metered billing.
2. **It embodies the constitution.** The leaf-only invocation
   (`--disallowedTools "*"` + `--strict-mcp-config`, no `--mcp-config`) is the
   constitution's *"intelligence, not agency"* applied: we invoke a full agent
   (Claude Code) and strip its tools/MCP so it behaves as a pure advisory model —
   no recursion back into frontier-advisor, no pi-subagents. Verified live
   (`tools:[]`, `mcp_servers:[]`). Honest-failure shows up too: a rate-limited or
   error consult *raises* and falls through to OpenAI rather than fabricating.
3. **Cost model shifted, deliberately.** Consults are now zero-*dollar* but draw
   the Max plan's `default_claude_max_5x` quota. Per the project owner, the agent
   must **not** litigate this — cost is the human's ledger; "subagents are free"
   stands.
